## Benchmark Methodology & Primary Metrics

- **Primary Metric &mdash; Critical Token Accuracy**: Direct entity-level verification comparing raw prescription entities (drug name, strength, dose, schedule, duration, expiry date) with ASR acoustic transcriptions.

- **Secondary Metric &mdash; Word Error Rate (WER)**: Acoustic accuracy score generated by transcribing synthesized audio via `faster-whisper` (`small.en`, `int8`, `beam_size=5`) and comparing against normalized ground truth via `jiwer`.

- **Secondary Metric &mdash; Phoneme Error Rate (PER)**: G2P transliteration edit distance using `Epitran` G2P (`eng-Latn`).
